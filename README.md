The project contained here is a Pac-Man inspired maze game I developed from scratch as a birthday gift for my sister, who always loved the classic arcade game. At the time, I was recovering from reconstructive surgery to my wrist and had to code the entire game with a single arm, but because of my sheer dedication to any task I take on, I completed it with time to spare.
